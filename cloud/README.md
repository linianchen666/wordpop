# Supabase 云同步配置

1. 在 https://supabase.com 创建项目，在 SQL Editor 执行 [supabase.sql](supabase.sql)。该脚本可重复执行。
2. 在 Authentication 开启 Email 登录。保留邮件确认时，注册后先确认邮件再登录。
3. 在项目 API 设置找到项目 URL 和公开的 publishable key（旧项目可用 anon key）。不要把 service_role 或 secret key 填入应用。
4. 先使用包含云同步功能的电脑版本：设置 → 电脑与手机云同步，填写 URL、公开密钥，注册或登录。电脑当前记录作为初始进度上传。
5. 安卓安装 APK，在云同步设置中用同一项目和账户登录。

电脑和已打开的手机应用每 5 秒同步，手机操作小组件后也尝试同步。Android 后台由 WorkManager 调度，最短周期 15 分钟，系统休眠时可能进一步延迟；不保证息屏待机时实时刷新。没有依赖 Google 推送服务。

评分事件使用唯一 ID，重复上传不会重复评分；按评分时间及 ID 排序重算 FSRS，两个设备同时评分时保留双方事件。设备时间早于已有记录时以已有记录时间计算记忆，原评分时间仍保留。Windows 撤销作为撤销事件同步。初始云快照和事件归登录账户所有，RLS 隔离不同用户。

手机首次连接时采用电脑初始快照中的学习设置；之后两端设置分别选择，实时同步的是学习记录和评分；手机词库为内置四级、六级、考研。账号连接后不要在电脑直接导入另一份备份覆盖本地记录；请先退出云同步，并为不同学习账户使用独立本地配置。服务器建表及真实账户连接需要使用者完成；本地模拟接口验证不等于已在你的 Supabase 项目验证。
