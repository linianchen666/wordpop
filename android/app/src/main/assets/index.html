电脑与手机云同步

先在电脑端初始化云记录，再用同一账户登录手机。评分立即保存在本地，约 10 秒批量上传；前台每 15 秒轻量检查，离开 App 时补传。后台更新受系统限制，可能延迟。

高级连接设置

确认链接打不开？

点击邮件后若跳到 localhost 并打不开，邮箱可能已经确认，请回软件尝试登录。仍未确认时，在 Supabase → Authentication → URL Configuration 将 Site URL 改为可访问的 HTTPS 网页（例如 https://github.com/linianchen666/wordpop），保存后重发确认邮件，点击最新链接，再回软件登录。
