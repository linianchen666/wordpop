# WordPop v1.9.3 正式版

Windows 1.9.3 与 Android 0.1.7：修复安卓批量同步格式问题，并提供更明确的云同步错误提示。

- **安卓同步 400 修复**：普通评分与撤销记录统一上传字段，普通评分显式发送空的 `target_id`，避免混合批次被云接口拒绝。离线重试仅发送约定的事件字段，服务器生成的 `created_at` 不回传，保留增量下载的服务器时间语义。
- **明确同步错误**：区分读取初始记录、上传评分、检查记录数量和下载评分，显示 HTTP 状态及服务错误码。云表字段、校验规则和权限问题分别提示；登录状态与同步结果分别显示。
- **保留待同步记录**：上传格式修复不清空本地评分、撤销、同步确认或下载缓存。覆盖安装后可继续补传，不需要为此格式问题重建数据库或修改 Supabase 表。
- **兼容升级**：Android 采用非调试 release 构建，沿用固定签名，versionCode 升为 9。保留现有三星外屏组件、桌面组件、账号、学习记录及外观设置，两端沿用上一版统一图标。

## 安装与同步

- **Android**：下载 `WordPop.Android.0.1.7.apk` 直接覆盖安装；0.1.5 及更新版本可从 App 菜单 →“检查更新”进入。已登录时升级后打开 App，点击“立即同步”重试待上传记录。若仍失败，请依据新增的步骤及错误码排查，登录成功后的同步错误无需反复输入密码。
- **Windows**：从托盘退出后运行 `WordPop.Setup.1.9.3.exe`，或通过托盘“检查更新”进入发布页。Windows 本版同步逻辑沿用上一版。
- 从 0.1.2 起的固定签名安卓包可覆盖升级；0.1.0 / 0.1.1 旧临时签名版本仍需先同步、备份，再重装恢复。卸载或清除应用数据会删除手机本地记录。

已收到 Z Flip7 用户反馈：0.1.6 的外屏小组件能够添加并使用。本版保留该功能；其他 One UI 版本、地区和锁屏策略仍需分别确认。

两端安装包及 `SHA256SUMS.txt` 位于同一发布页。
