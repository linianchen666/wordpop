# WordPop v1.9.1 正式版

Windows 1.9.1 与 Android 0.1.5：降低电脑和手机同步的下载流量，并为安卓加入检查更新入口。

- **只下载新增评分**：正常同步仅下载新增评分及撤销；初始快照、已有记忆记录继续使用。下载缓存按项目和账户保存在本地 SQLite，重启后可继续增量同步。
- **完整校验与失败恢复**：首次登录、手动“立即同步”、缓存异常、每 24 小时及增量数量核对出现缺口时，完整读取历史。分页保留服务器时间的微秒精度，并以 UUID 区分同一时间的事件；离线旧评分及延迟提交事务不会因时间游标漏掉。两端同时评分时继续增量补取，下载或合并失败不推进缓存。
- **安卓检查更新**：右上角菜单 →“检查更新”，显示当前版本、最新安卓版本与更新说明，独立于 Windows 发布标签比较。发现新版可点“下载 APK”，通过浏览器下载后由系统确认覆盖安装。支持取消和失败重试，关闭 App 后不会弹出旧检查结果。只检查正式版，不自动下载或自动安装。
- **记录与签名兼容**：Android 使用非调试 release 构建并沿用固定签名，versionCode 升为 7；从 0.1.2 起的固定签名包可直接覆盖安装并保留账号、学习进度和小组件外观。首次启动自动增加本地下载缓存表，保留原学习记录。无需重新执行 Supabase SQL，也无需重新注册云账户。

## 安装与升级

- **Android**：0.1.4 及更早版本没有检查更新入口，本次请先手动下载 `WordPop.Android.0.1.5.apk` 覆盖安装，之后可通过 App 内入口检查正式更新。
- **Windows**：从托盘退出现有版本，再运行 `WordPop.Setup.1.9.1.exe`；已有正式版可通过托盘“检查更新”打开新版发布页，保留本地记录。
- 旧临时签名 0.1.0/0.1.1 需先在旧 App 完成云同步并在电脑导出备份，再重装恢复；0.1.2 起固定签名包不需卸载。

评分仍立即保存在本地，以 10 秒固定窗口批量上传，前台每 15 秒检查新记录；后台同步受 Android 待机、节电及网络影响，可能延迟。FSRS 与原有复习规则沿用。三星外屏继续通过 Good Lock / MultiStar 打开背词界面，未接入外屏原生第三方小组件。

两端安装包及 `SHA256SUMS.txt` 位于同一发布页。
