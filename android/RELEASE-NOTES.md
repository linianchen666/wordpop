Android 0.1.3-beta.1 与 Windows 云同步预览 1.9.0-beta.4。Windows 正式 Latest 仍为 v1.8.6，本次以测试版发布。

- **触屏撤销**：App 和普通/紧凑小组件顶部新增 ↶，撤销手机的上一条评分并返回原词重新选择；恢复 FSRS、计数和新词名额。重启后保留入口，离线撤销也会同步到电脑。后续对同一词有新评分时，旧入口失效，旧按钮和连点不会重复撤销。
- **发音时机**：App 和小组件都在点击“显示释义”时自动发音，换词、评分、撤销和定时同步保持安静；保留手动发音按钮和自动发音开关。
- **学习响应**：复用学习引擎会话，正常评分只计算当前词，撤销只回放涉及的单词，不重复计算其他单词的完整历史；界面只接收显示数据。显示释义即时展开，待保存操作防止重复提交，失败保留可重试状态，旧回调不覆盖新卡片。
- **云同步**：评分先在本地保存，约 750 毫秒后后台上传；同步中新增评分自动续传，离线/回执丢失时保留并重试。查看卡片、显示释义和调整小组件不触发上传；无新记录时不重写学习状态、不重置队列。手机增加联网补传任务，电脑同步其他词时保留本地逾期平摊安排。
- **登录设置**：项目网址和公开密钥收在高级连接设置中；登录期间明确显示验证状态，验证成功后再清空密码，失败保留密码并支持显示输入。三星外屏使用说明放在文档中，不再占用 App 设置。
- **兼容记录与签名**：沿用现有初始快照、评分/撤销事件和 Supabase 云表，不清空学习记录，无需重新执行 SQL。APK 沿用 0.1.2 的固定签名，versionCode 从 3 升为 4，0.1.2 用户可直接覆盖安装，保留手机本地数据。

由 0.1.0-beta.1、0.1.1-beta.1 等旧临时签名版本迁移时，先在旧手机 App 确认云同步成功并在电脑导出备份，再卸载旧 APK、安装新版并登录恢复；卸载会删除尚未上传的手机记录。Windows 从托盘退出现有版本后安装预览包，沿用本地记录。

App 打开时约每 5 秒检查两端记录，手机待机同步受系统调度限制，可能延迟。三星外屏继续通过 Good Lock / MultiStar 打开专注背词 App，未接入三星原生外屏小组件。发音需要手机的英语文字转语音数据和媒体音量；Z Flip7 实机的外屏、小组件及响应速度仍需安装后确认。
