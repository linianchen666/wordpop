Android 0.1.1-beta.1 与 Windows 云同步预览 1.9.0-beta.2。Windows 正式 Latest 仍为 v1.8.6，本次以测试版发布。

- 桌面小组件支持横向、纵向缩放，缩小时使用紧凑布局；背景不透明度可调 0–100%，支持完全透明，设置在本地保存。
- 小组件增加英语发音按钮；默认在点击释义或评分后切换下一词时自动发音，同一张卡片不重复播放。可关闭自动发音；后台定时刷新和云同步保持静音。
- 手机 App 与小组件统一为底部“不认识、模糊、认识”三个按钮，右上角星号表示“轻松 / FSRS Easy”。
- App 默认显示精简的专注背词页，设置收进右上角菜单。三星外屏继续通过 Good Lock / MultiStar 启动 App，未接入三星原生外屏小组件。
- 两端预填默认 Supabase 项目网址与公开 API 密钥，仍可修改。已连接账户保留自己的项目配置；邮箱和密码由用户填写。
- 注册增加重发确认邮件，区分邮箱未确认、密码错误、邮件限流等提示。确认后跳到 localhost 的项目需修改 Supabase 的 Site URL。
- 学习记录沿用同一套 FSRS 和 1 分钟 / 10 分钟确认规则，云同步协议保持兼容。

安装前请先在旧版本完成云同步，并保留学习记录备份。APK 仍为调试签名测试包。已核对签名：本次与 0.1.0-beta.1 不同，不能直接覆盖升级。请先在旧手机 App 点“立即同步”并确认成功，在电脑导出备份，再卸载旧 APK、安装新版，用同一云账户恢复已同步记录。卸载会清除手机本地数据，尚未上传的记录无法靠重新登录恢复。固定正式签名尚未配置。

Windows 从托盘退出现有版本后安装预览版，沿用本地学习记录。安卓发音需要手机的英语文字转语音数据和媒体音量；透明背景、缩放、自动发音及外屏在 Z Flip7 上仍需实机验证。
