# WordPop Android

Android 8.0 及以上，推荐更新 Android System WebView。针对三星 Z Flip7 的普通桌面与小屏应用界面，使用系统 AppWidget 小组件、原生 SQLite 持久化和 JavaScriptSandbox 执行与电脑端相同的 FSRS 库。

## 构建

在仓库根目录运行 `npm ci --ignore-scripts`，然后 `node android/tools/build-assets.cjs`。Android 构建需要 JDK 17、Gradle 8.11.1、Android SDK 35 和 Build Tools 35.0.0，设置 `ANDROID_HOME` 后运行 `gradle -p android assembleDebug lintDebug`。

APK 输出：`android/app/build/outputs/apk/debug/app-debug.apk`。GitHub 构建的测试包从 0.1.2-beta.1 开始使用固定 WordPop 签名；已按 [签名配置](SIGNING.md) 保存并验证 GitHub Secrets。首次从旧临时签名包迁移需要重装，此后保留密钥并递增 versionCode 可覆盖升级。未配置固定密钥的本地默认调试包不能作为覆盖升级包。仓库的 Android APK 工作流构建并通过模拟器执行设备测试。

## 使用

安装后打开应用，选择词库和新词计划；点击右上角菜单 →“添加桌面小组件”，也可长按桌面空白处 → 小组件 → WordPop。小组件先显示单词，点释义区展开，再选择不认识、模糊、认识，或点击右上角星号表示轻松。长按桌面小组件后拖动边缘可横向、纵向调整大小（网格范围由启动器决定）。最小尺寸放宽至 180×160 dp；小于 240 dp 宽或高时切换紧凑布局，保留单词、释义、发音、底部三个反馈和右上角星号，隐藏音标、计数和间隔文字；放大后恢复完整信息。调整大小不改变当前单词或复习记录。手机和小组件共用本地记录；离线也可评分。反馈规则与电脑版本一致：首次不认识/模糊后 1 分钟，答对再确认 10 分钟，确认后由 FSRS 安排跨日复习。

### 小组件背景与发音

小组件右上角的“背景”打开独立设置，背景不透明度可调 0–100%，0% 为完全透明。也可在 App 右上角菜单 →“小组件背景”统一应用到所有桌面小组件。启动器支持重新配置时，也可长按小组件进入设置。透明度保存在手机本地，更新应用后保留；透明背景下文字保留阴影。

点击小组件音标旁的“🔊 发音”直接朗读当前单词，无需打开 App。使用手机的英语文字转语音引擎，播放期间会有短暂的系统发音通知，结束自动退出播放服务。发音不可用时，请检查手机文字转语音设置里的英语语音数据和媒体音量；默认开启交互自动发音：点击显示释义时播放，换词和评分不自动发音，同一张卡片不会重复自动朗读。在小组件的“背景”设置或 App 菜单 →“小组件背景”中可关闭“背词时自动发音”。定时刷新、缩放、云同步不会自动发声；系统限制后台启动播放服务时，可点发音按钮手动播放。

云配置及合并规则见 [Supabase 说明](../cloud/README.md)。当前源码先在本地保存评分，约 750 毫秒后后台上传，同步期间新增评分会接着上传；显示释义或缩放小组件不触发同步。应用打开时约每 5 秒检查电脑的新评分，无新记录时跳过学习状态重写和小组件更新。评分还登记联网补传任务，后台接收电脑记录保留最短 15 分钟的周期检查；系统待机限制可能使任务延迟，不保证实时。这些同步优化将在下一次安装包发布时提供。

## 三星外屏

普通桌面支持标准 AppWidget。Z Flip7/One UI 是否允许把第三方 AppWidget 直接放到外屏，必须在实际手机上确认；目前未验证，不声称已支持原生外屏小组件。

应用默认进入专注背词页，只显示进度、单词、音标、发音、释义、底部三个评分和右上角轻松星号，学习设置及云同步收进右上角菜单。小屏下自动缩小间距；完整释义可展开并滚动。若系统外屏不提供 WordPop 小组件，可通过三星 Good Lock → MultiStar 的外屏应用启动器允许并打开 WordPop（具体入口随 One UI 和地区变化）。这是外屏运行应用的替代方案，不能等同于直接添加外屏小组件。

小屏布局通过浏览器多个视口验证；本次新增的透明背景和语音服务尚需在 Z Flip7 实机验证。三星外屏原生小组件限制不会因更换普通 AppWidget 元数据而自动解除。

App 点击显示释义后立即展开已加载的释义和按钮，后台完成状态确认；评分过程中禁止重复提交，旧回调不会覆盖新卡片，保存失败时会恢复界面并显示提示。传回页面的数据只包含显示所需内容，完整学习记录仍保存在本地数据库。

项目网址和公开密钥默认收在“高级连接设置”中。登录期间显示等待提示并锁定重复提交，密码验证成功后立即显示登录成功，再继续同步；失败时保留密码供修改，并可通过显示密码按钮检查输入。三星外屏使用方式保留在本文，不作为 App 设置项。学习引擎复用会话状态，正常评分只更新当前单词，云撤销或乱序事件仍完整回放校验。
