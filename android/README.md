# WordPop Android

Android 8.0 及以上，推荐更新 Android System WebView。针对三星 Z Flip7 的普通桌面与小屏应用界面，使用系统 AppWidget 小组件、原生 SQLite 持久化和 JavaScriptSandbox 执行与电脑端相同的 FSRS 库。

## 构建

在仓库根目录运行 `npm ci --ignore-scripts`，然后 `node android/tools/build-assets.cjs`。Android 构建需要 JDK 17、Gradle 8.11.1、Android SDK 35 和 Build Tools 35.0.0，设置 `ANDROID_HOME` 后运行 `gradle -p android assembleDebug lintDebug`。

APK 输出：`android/app/build/outputs/apk/debug/app-debug.apk`。GitHub 构建的测试包从 0.1.2-beta.1 开始使用固定 WordPop 签名；已按 [签名配置](SIGNING.md) 保存并验证 GitHub Secrets。首次从旧临时签名包迁移需要重装，此后保留密钥并递增 versionCode 可覆盖升级。未配置固定密钥的本地默认调试包不能作为覆盖升级包。仓库的 Android APK 工作流构建并通过模拟器执行设备测试。

正式发布选择工作流的 `release` 变体，使用同一固定签名生成非调试 APK，执行 `assembleRelease testReleaseUnitTest lintRelease -PwordpopReleaseTests=true` 和 `connectedReleaseAndroidTest -PwordpopReleaseTests=true`。正式 APK 输出为 `android/app/build/outputs/apk/release/app-release.apk`；本地构建也需先按签名说明配置固定密钥环境变量。`wordpopReleaseTests` 让设备测试验证实际 release 变体，默认仍测试 debug。

[下载 Android 0.1.7 正式版](https://github.com/linianchen666/wordpop/releases/download/v1.9.3/WordPop.Android.0.1.7.apk)，与 Windows 1.9.3 一起发布。Android versionCode 为 9，0.1.2 起的固定签名包（包括 0.1.4-beta.1）可直接覆盖升级，保留账号和学习记录。

## 使用

安装后打开应用，选择词库和新词计划；点击右上角菜单 →“添加桌面小组件”，也可长按桌面空白处 → 小组件 → WordPop。小组件先把单词与音标居中显示，点击英文或中间区域展开释义；展开后单词上移，再选择不认识、模糊、认识，或点击右上角星号表示轻松。长按桌面小组件后拖动边缘可横向、纵向调整大小（网格范围由启动器决定）。最小尺寸放宽至 180×160 dp；小于 240 dp 宽或高时切换紧凑布局，保留单词、释义、发音、底部三个反馈和右上角星号，隐藏音标、计数和间隔文字；放大后恢复完整信息。调整大小不改变当前单词或复习记录。手机和小组件共用本地记录；离线也可评分。反馈规则与电脑版本一致：首次不认识/模糊后 1 分钟，答对再确认 10 分钟，确认后由 FSRS 安排跨日复习。

### 检查软件更新（Android 0.1.5 起）

打开 App 右上角菜单 → **检查更新**。设置页和检查弹窗显示当前安装的安卓版本；弹窗提供最新安卓版本及更新说明。检查只访问 GitHub 的最新正式发布，按 `WordPop.Android.X.Y.Z.apk` 附件识别安卓版本，不使用 Windows 的发布标签，也不提示测试版或降级安装；同版本的测试版可升级到正式版。检查不需要登录云账户，也不消耗 Supabase 数据库额度。

发现新版后点“下载 APK”，由系统浏览器打开本仓库的 HTTPS 下载地址；下载完成后在系统中确认覆盖安装，沿用固定签名并保留学习记录。也可点“发布页”查看完整说明。检查中可取消，网络失败时可重试；不会自动下载或自动安装。Android 0.1.4 及更早版本没有该入口，请先手动覆盖安装最新正式版，以后可从此入口检查正式更新。

### 同步 400 修复（Android 0.1.7）

评分、撤销和离线重试统一上传字段，修复同一批记录字段不一致导致的 400；服务器生成的 `created_at` 不回传。失败时保留本地记录，覆盖安装后可继续补传。同步报错区分初始记录、上传、数量检查和下载步骤，并显示 HTTP 状态及服务错误码；如果仍报错，可按该码排查云表或权限配置，详见 [同步排查](../cloud/README.md#安卓同步-400-排查)。

### 点错评分时撤销

Android 0.1.3-beta.1 增加了触屏撤销。App 和普通/紧凑两种小组件顶部的 **↶** 表示“撤销上次评分”；只有存在可撤销评分时显示。点击后回到刚才的单词，释义已展开，可直接重新选择不认识、模糊、认识或轻松；同时恢复复习时间、答题计数和新词名额。暂时完成后也可撤销。

只提供手机上最后一次评分的单步撤销，入口在正常刷新、同步和重启后保留；新评分替换旧入口，改变学习设置清除入口。如果电脑随后对同一单词又有新评分，旧入口失效；其他单词的评分不影响它。旧按钮或连续点击不能重复撤销。

离线也可撤销，撤销作为指向原评分的独立事件保存并同步，原评分已上传时也能撤销；手机和电脑合并后重新计算该词的记忆状态，恢复对应日期的学习统计。撤销不自动发音。旧安装包尚无此入口，升级后由新产生的评分提供撤销。

### 小组件背景与发音

小组件右上角的“背景”打开独立设置，背景不透明度可调 0–100%，0% 为完全透明。也可在 App 右上角菜单 →“小组件背景”统一应用到所有小组件（含已添加的外屏组件）。启动器支持重新配置时，也可长按小组件进入设置。透明度保存在手机本地，更新应用后保留；透明背景下文字保留阴影。

点击小组件音标旁的“🔊 发音”直接朗读当前单词，无需打开 App。使用手机的英语文字转语音引擎，播放期间会有短暂的系统发音通知，结束自动退出播放服务。发音不可用时，请检查手机文字转语音设置里的英语语音数据和媒体音量；默认开启交互自动发音：App 点击“显示释义”或小组件点击中间的英文时播放，换词和评分不自动发音，同一张卡片不会重复自动朗读。在小组件的“背景”设置或 App 菜单 →“小组件背景”中可关闭“背词时自动发音”。定时刷新、缩放、云同步不会自动发声；系统限制后台启动播放服务时，可点发音按钮手动播放。

云配置及合并规则见 [Supabase 说明](../cloud/README.md)。Android 0.1.5 先在本地保存评分，以首条评分起 10 秒的固定窗口批量上传，后续评分不延长窗口；离开 App 或点击“立即同步”可提前补传，同步期间新增评分进入下一批；显示释义或缩放小组件不触发同步。App 的本地卡片每 5 秒检查是否有词到期；云端检查单独降至每 15 秒，先查询账户事件总数，数量不变时不下载完整日志、不重写状态或更新小组件。有新评分时只下载新增事件，缺少有效数量响应时自动回退完整读取。评分还登记联网补传任务，后台接收电脑记录保留最短 15 分钟的周期检查；系统待机限制可能使任务延迟，不保证实时。与配套 Windows 1.9.1 共享记忆记录，无需重新建表。

Android 0.1.5 增加增量下载：按服务器 `created_at` 和 UUID 保留微秒精度分页，只下载新评分及撤销，本地 SQLite 保存按项目和账户隔离的下载缓存，重启后可续用。首次登录、手动“立即同步”、缓存异常、每 24 小时完整校验及记录数量核对出现缺口时完整读取；断网或合并失败不会推进缓存。旧时间的离线评分、延迟提交事务通过数量核对和完整回退补齐。使用现有云表，无需重新执行 SQL。详见 [同步规则](../cloud/README.md)。

## 三星外屏

Android 0.1.6 已新增独立的 **WordPop 外屏背词** 小组件，采用三星公开 Flex Window 接口：标准 `keyguard` 类别加三星 `display="sub_screen"` 元数据。它与普通桌面组件分别注册，共用本地学习记录、评分、撤销、发音和同步；外屏布局为小屏调整了按钮和文字。Android 0.1.5 及更早版本不包含此外屏组件。

安装 Android 0.1.6 或更新版本后，先打开 App 初始化词库，再进入三星 **设置 → 外屏 → 小组件**，查找 WordPop / WordPop 外屏背词并启用；具体入口随 One UI 和地区变化。添加后可直接在组件里显示释义、选择底部三个反馈或右上角轻松星号，无需先通过 MultiStar 启动 App。组件背景设置也应用到外屏组件。

实现依据是三星的 [Flex Window 开发文档](https://developer.samsung.com/galaxy-z/flex_window.html)和[原生小组件教程](https://developer.samsung.com/codelab/galaxy-z/widget-flex-window.html)。这些公开接口最初面向 Flip5；本仓库可以验证组件声明、布局和评分交互，但普通 Android 模拟器不能验证 Flip7 的三星外屏列表。已有 **Z Flip7 用户确认可添加并使用**；其他 One UI 版本、地区和锁屏策略仍需分别确认。

若新版仍不出现在列表，可尝试第三方 [CoverWidgets](https://play.google.com/store/apps/details?id=apps.ijp.coverwidgets)，将 WordPop 的普通桌面组件放入外屏；其商店说明列出 Flip7 / One UI 8 支持，并要求无障碍权限，部分功能可能付费。这是可选的独立工具，WordPop 不依赖它。原有 Good Lock → MultiStar 外屏应用启动器方案也保留。应用默认进入专注背词页，小屏下缩小间距，完整释义可展开并滚动；这是运行 App 的替代方式。

App 点击显示释义后立即展开已加载的释义和按钮，后台完成状态确认；评分过程中禁止重复提交，旧回调不会覆盖新卡片，保存失败时会恢复界面并显示提示。传回页面的数据只包含显示所需内容，完整学习记录仍保存在本地数据库。

项目网址和公开密钥默认收在“高级连接设置”中。登录期间显示等待提示并锁定重复提交，密码验证成功后立即显示登录成功，再继续同步；失败时保留密码供修改，并可通过显示密码按钮检查输入。三星外屏使用方式保留在本文，不作为 App 设置项。学习引擎复用会话状态，正常评分只更新当前单词，云撤销或乱序事件仍完整回放校验。
