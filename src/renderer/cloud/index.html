电脑与手机云同步

先在 Supabase 项目执行建表脚本。电脑端第一次连接会上传当前记录作为初始进度，然后在手机上登录同一账户。两端使用期间定期同步；手机待机时更新可能延迟。

确认链接打不开？

点击邮件后若跳到 localhost 并打不开，邮箱可能已经确认，请回到软件尝试登录。仍提示未确认时，检查 Supabase → Authentication → URL Configuration 的 Site URL，将默认 localhost 改为可访问的 HTTPS 网页（例如 https://github.com/linianchen666/wordpop），保存后重发邮件并点击最新链接。确认后需要手动返回软件登录。

链接过期或已使用时，请先尝试登录；仍未确认，再重发确认邮件。
