# 📖 WordPop

**基于动态间隔复习的 Windows 桌面弹窗背单词工具**

[![Latest Release](https://img.shields.io/github/v/release/linianchen666/wordpop?label=latest)](https://github.com/linianchen666/wordpop/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows-blue)](https://github.com/linianchen666/wordpop/releases/latest)

当前源码版本：**1.5.2**

## ✨ 特性

- **🎙️ 多角色音色发音引擎** — 软萌萝莉音、知性御姐音、磁性大叔音、标准美音/英音、极速突击音自由切换，支持设置面板实时试听，让背单词充满沉浸与趣味
- **⏱️ 微批次防打扰与智能冷却** — 支持 1 词即走、3 词一轮或 5 词小冲刺，每轮完成后展示微结算并进入 10 分钟静默冷却，绝不连环打扰工作心流
- **🚀 沉浸专注刷词模式 (Focus)** — 专为考前冲刺、番茄钟休息和集中消化积压打造的 680×540 居中大字面板，内置连击火焰 Streak、实时反馈与详细结算报告
- **💊 灵动极简胶囊形态 (Pill Mode)** — 极窄 320×56 透明毛玻璃胶囊形态，常驻屏幕边缘，零遮挡日常办公、编程与文档写作
- **🎯 智能目标规划模式** — 设定目标完成日期（如考试日），系统每天自动根据 `剩余词量 ÷ 剩余天数` 自适应调整每日新词，无需反复手动配置
- **⚖️ 智能复习负荷平衡** — 当待复习单词积压较多时，系统自动智能减半或熔断暂停推新（新词 = 0），优先全力消化旧词，彻底杜绝“旧债未清又添新词”
- **🌊 逾期积压一键平摊** — 停背数天产生大量逾期单词时，可一键将积压词智能均匀分散到接下来的 3、5 或 7 天，秒级化解复习焦虑
- **🧠 动态间隔复习** — 使用 FSRS-6，根据每个词的难度、稳定性和实际复习时间安排下一次复习；弹窗与专注模式共用算法
- **💡 两阶段交互** — 先看单词主动回忆，再点击/快捷键展开释义，训练真正的记忆能力
- **📊 四种记忆反馈** — 不认识、模糊、认识、轻松分别对应 FSRS 的 Again、Hard、Good、Easy 评分
- **★ 轻松反馈** — 容易回忆的词按 FSRS Easy 评分延长复习间隔，继续长期巩固
- **📚 多词库进度继承** — 支持单词多词库归属（多对多关联），切换或多选词库时自动继承已有记忆状态，无需重复背诵共有词
- **💾 一键备份与恢复** — 支持导出与导入全部学习进度、复习阶段、打卡记录与个性化设置，轻松换机与跨设备迁移
- **🔍 词根词源助记** — 内置前缀、词根、后缀深度拆解与衍生关联词提示，理解构词法倍增记忆效率
- **⌨️ 全键盘快捷键** — 全键盘流畅操作，无需鼠标
- **📈 丰富学习统计** — 今日已复习/已新学、今日待复习/待新学、累计数据、连续打卡、7天趋势和阶段分布
- **🔄 开机自启与在线更新** — 可选开机自动启动，内置版本检测与无损迁移保障

## 🚀 下载安装

1. 前往 [Releases](https://github.com/linianchen666/wordpop/releases/latest) 下载最新版 `WordPop Setup X.X.X.exe`
2. 双击运行安装程序
3. 如果旧版 WordPop 正在运行，安装程序会自动提示关闭
4. 安装完成后启动，首次运行会弹出设置向导
5. 选择词库和每日词量，开始背单词

## 🧠 复习机制

WordPop 使用 **FSRS-6（Free Spaced Repetition Scheduler）**，直接调用 Open Spaced Repetition 项目的 [`ts-fsrs`](https://github.com/open-spaced-repetition/ts-fsrs) 库（锁定版本 5.2.3，兼容 Electron 28 的 Node 18 运行时）。普通弹窗和专注刷词共用同一套 FSRS 状态与数据库事务。

### 评分与记忆模型

| 界面反馈 | FSRS 评分 | 含义 |
|---------|-----------|------|
| **✗ 不认识** | Again | 回忆失败，需要重学 |
| **~ 模糊** | Hard | 能回忆但吃力，需要更近的复习 |
| **✓ 认识** | Good | 正常回忆 |
| **★ 轻松** | Easy | 容易回忆，可安排更远的复习 |

旧版“熟知”按钮改为“轻松”。Easy **不再直接标记已掌握或停止推送**；旧接口名 `mastered` 兼容映射为 Easy，避免旧渲染器绕过 FSRS。

FSRS 为每个词保存独立的难度 **D**、稳定性 **S**、学习/复习/重学状态、累计复习次数、遗忘次数和最后复习时间。它根据经过的实际时间计算记住的概率 **R**，结合本次评分更新记忆状态，再按目标记忆率决定复习时间。**旧 E-Factor 不参与调度**，仅为旧备份兼容保留。

### 默认设置与短期学习

- 目标记忆率：**90%**，含义是计划在模型预测记住概率接近 90% 时复习，并非保证实际正确率。
- 使用 FSRS-6 默认权重，开启短期学习，关闭随机间隔扰动。
- 学习步骤采用库默认的 **1 分钟、10 分钟**；重学步骤为 **10 分钟**。
- 新词首次反馈在当前参数下：Again 约 **1 分钟**，Hard 约 **6 分钟**，Good 约 **10 分钟**，Easy 约 **8 天**。随后按真实记忆状态重新计算，不使用固定的 5 分钟→30 分钟→4 小时阶梯。
- 最长计划间隔为 **90 天**。仅限制到期时间，不截断记忆稳定性，也不自动标记已掌握。
- 每次复习保存原始 FSRS 日志和前后记忆状态。目前使用默认权重，**尚未实现根据个人历史自动训练权重**；逐词状态仍会随反馈更新。

### 调度、迁移与备份

- 到期复习词优先于新词，新词按内置词频排列。每次普通弹窗取词前重新查询到期词；专注模式在获取下一批词时读取到期词。
- 默认每批 3 个词，完成后冷却 10 分钟；冷却、暂停、当前单词尚未处理或应用未运行，都可能使实际弹出晚于计划时间。可选择连续模式或缩短冷却。
- 只调度当前选中的词库。自动负荷平衡开启时，积压达到 40 个则新词配额减半，达到 80 个则暂停推新。
- 数据库升级到 **schema v7**，新增 FSRS 卡片状态与复习历史。升级保留旧词库、到期时间、统计和已掌握状态；迁移失败会报错并保留原数据库，不删除学习数据。
- 没有完整历史的旧词，在下一次反馈时按原间隔估算初始稳定性、使用默认初始难度，再由 FSRS 更新。不会把这份估算描述为完整历史重建；旧版已掌握的词保持停用状态。
- 新备份完整保存 FSRS 状态与日志，继续支持旧备份。撤销反馈会同时恢复原记忆状态、统计并删除本次日志。

实现：`src/main/review-algorithm.js`（FSRS 适配）、`src/main/review-progress.js`（共享事务）、`src/main/fsrs-schema.js`（迁移）。验证：`test/fsrs-review.test.js`。

## 📊 学习进度预测

设置页面内置**预测卡片**，帮你合理规划学习节奏：

- **进度概览** — 进度条 + 总计/已学/已掌握/剩余数字
- **预测天数** — 根据每日新词数和剩余单词自动计算预计完成日期
- **目标日期** — 设置希望什么时候背完，自动反推每天需要学多少新词
- **自定义词量** — 支持任意每日词量（1-200），不再局限于预设选项

## 🔧 体验设计

### 不抢焦点

弹窗出现时**不会抢走键盘焦点**，你可以在其他软件中继续打字、写代码。弹窗通过边框闪烁提示新词到来，想操作时点击弹窗即可。

### 连续刷词

背完一个单词后，下一个词立即弹出，不需要等待。弹窗一直在屏幕角落，你可以随时处理，也可以集中一口气刷完当天的量。

## 🛠 技术栈

- **Electron 28** — 桌面应用框架
- **better-sqlite3** — 本地 SQLite 数据库（WAL 模式，当前 Schema 版本 v7）
- **ts-fsrs 5.2.3** — FSRS-6 记忆模型与复习间隔计算
- **原生 HTML/CSS/JS** — 轻量渲染，无框架依赖
- **electron-builder** — 打包与分发（NSIS 安装程序）

### 代码结构

应用使用 Electron 主进程、隔离的 preload API、原生 HTML/CSS/JavaScript 界面和 SQLite。学习逻辑按职责拆分，普通弹窗与专注模式共用 FSRS 评分和数据事务：

| 模块 | 职责 |
|------|------|
| `study-policy.js` | 每日新词配额、负荷平衡与批次配置的纯计算 |
| `study-scheduler.js` | 取词、暂停恢复、冷却和撤销；通过事件通知展示层，不依赖 Electron 或 SQL |
| `scheduler-presenter.js` | 把学习事件转换为弹窗展示、隐藏和批次结算 |
| `scheduler.js` | 组装实际数据库、时钟与窗口依赖，保留原调度器接口 |
| `focus-session.js` / `focus-window.js` | 专注学习业务与窗口生命周期分别管理 |
| `learning-repository.js` | 集中学习查询、统计、积压平摊与撤销的数据访问 |
| `review-algorithm.js` / `review-progress.js` | FSRS 计算与进度、历史、每日统计的原子写入 |
| `db.js` / `fsrs-schema.js` / `backup.js` | 数据库初始化、迁移、词库导入与备份恢复 |
| `ipc-handlers.js` | 显式、幂等注册界面通道，调用业务模块和数据访问层 |

核心模块采用工厂函数注入数据库、时钟和计时器，便于使用真实 SQLite 验证业务。关键回归测试直接调用生产代码，覆盖 FSRS、调度冷却、评分失败重试、专注模式、数据查询和 IPC；窗口测试替换 Electron 外壳。测试分别在独立进程和临时数据目录运行。
