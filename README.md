# 📖 WordPop

**基于 FSRS 的 Windows 桌面弹窗背单词工具**

[![Latest Release](https://img.shields.io/github/v/release/linianchen666/wordpop?label=latest)](https://github.com/linianchen666/wordpop/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows-blue)](https://github.com/linianchen666/wordpop/releases/latest)

当前正式版及源码版本：**1.8.1**。支持 Windows x64。

## 下载安装与更新

1. 前往 [最新正式版](https://github.com/linianchen666/wordpop/releases/latest)，下载 `WordPop.Setup.X.X.X.exe`。
2. 从托盘退出正在运行的旧版，再运行安装程序。
3. 首次使用会打开设置页面，选择词库、每日新词量和学习节奏。
4. 升级已有安装时保留学习数据；旧记忆记录的处理见下方「升级与数据」。

发布页的 `SHA256SUMS.txt` 提供安装包校验值。

右键托盘图标，选择「检查更新」，发现新版后可打开下载页面，下载并安装。开启自动检查时，应用启动约 30 秒后检查一次，随后每 24 小时检查。更新检查读取 GitHub 的正式 **Latest Release**，不会推送测试版，也不会自动安装。

## 主要功能

- **FSRS 自适应复习**：每个单词保存独立记忆状态；普通卡片和专注模式使用相同算法，并显示各反馈对应的下次复习间隔。
- **两阶段回忆**：先看单词主动回忆，再展开释义并选择反馈；右上角星号表示「轻松」。
- **可调整大小的复习卡片**：拖动窗口边缘或角落调整尺寸，卡片记住调整结果。卡片外围透明，内容区域有填充背景。
- **独立任务栏胶囊**：开关立即生效，与正常卡片同时使用；深色小胶囊轮播需要巩固的单词和释义。
- **微批次与冷却**：支持每批 1、3、5 个词或连续模式；默认每批 3 个词，完成后冷却 10 分钟，冷却时长可调整。
- **专注刷词**：独立、可调整大小的专注窗口，支持键盘评分、连击提示和批次结算。
- **学习规划**：固定每日新词量或按目标日期计算配额，支持每日 1–200 个新词；复习积压较多时自动减半或暂停推新。
- **积压平摊**：将逾期复习分散到接下来的 3、5 或 7 天。
- **词库与发音**：内置四级、六级、考研词库，支持自定义词表、共享词进度继承、英美音及角色音色试听。
- **助记与统计**：词根词源助记、今日与累计学习统计、连续打卡及趋势展示。
- **备份与恢复**：导出、导入学习进度、FSRS 状态和评分日志、打卡记录、自定义词汇及设置。

## 使用方法

### 复习卡片

先尝试在不看释义的情况下想起单词含义，再点击「显示释义」或按空格。展开后，底部提供「不认识」「模糊」「认识」，右上角 ★ 提供「轻松」反馈。按钮旁显示本次评分后的计划复习间隔，标题显示当前学习状态和剩余词数。

| 反馈 | FSRS 评分 | 选择依据 |
|---|---|---|
| ✗ 不认识 | Again | 想不起含义，需要重学 |
| ~ 模糊 | Again | 只记得一点，需要看释义才能确认 |
| ✓ 认识 | Good | 不看释义也能独立想起含义 |
| ★ 轻松 | Easy | 能轻松、准确地想起含义 |

「模糊」按回忆失败处理，因此可能与「不认识」显示相同的短间隔。FSRS 的 Hard 表示“费力但独立答对”，与这里的「模糊」含义不同。Easy 会继续安排复习；旧版「熟知」直接停止推送的行为已改为「轻松」反馈。

### 卡片快捷键

| 快捷键 | 回忆阶段 | 展开释义后 |
|---|---|---|
| 空格 | 显示释义 | 发音 |
| → / D | 显示释义 | 认识 |
| ↓ / S | — | 模糊 |
| ← / A | — | 不认识 |
| Enter | 显示释义 | 认识 |
| M | — | 轻松 |
| Esc | 最小化 | 最小化 |

点击单词或音标可发音；右键托盘图标可暂停、恢复、打开设置、统计或专注模式。

### 灵动胶囊

在设置中开启「灵动胶囊」，**立即生效并保存**，无需再点击保存按钮。胶囊显示在主屏任务栏内部的中间位置，采用炭黑底色和浅色文字，宽度约 **133**、高度最多 **48** 个逻辑像素，适配任务栏高度。它只显示单词和释义，较长的单词会适当缩小字号，过长的内容会省略。

胶囊每 **8 秒**换一个词。候选来自当前选择的词库，排除旧版已掌握词，满足以下任一条件：

- 最近一次评分为 Again，包括新版的「不认识／模糊」。
- 累计至少 3 次困难反馈，且困难反馈占全部反馈的比例达到 40%。

困难反馈统计包含「不认识／模糊」及旧版 Hard。优先显示最近评分为 Again 的词，最多轮播 30 个；没有候选词时显示空状态。

胶囊的鼠标点击穿透到任务栏，不接收点击，也没有刷新按钮。它仅用于浏览提醒，不自动评分、不改变 FSRS 时间或学习统计。关闭开关只关闭胶囊，普通复习卡片照常使用。

## 复习机制

WordPop 使用 [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) **5.2.3** 实现 **FSRS-6**。每个词保存难度、稳定性、学习／复习／重学状态、复习次数、遗忘次数和最后评分时间，根据真实经过的时间及反馈计算下一次复习。

### 当前参数

- 目标记忆率 **90%**：在模型预测的记住概率接近 90% 时安排复习，不代表保证实际正确率。
- 使用 FSRS-6 默认权重，开启短期学习，关闭随机间隔扰动；尚未根据个人历史训练权重。
- 新词学习步骤为 **1 分钟、10 分钟**，重学步骤为 **10 分钟**。
- 新词首次反馈：「不认识／模糊」约 1 分钟，「认识」约 10 分钟，「轻松」约 8 天。后续间隔按记忆状态计算。
- 长期复习词回忆失败后进入约 10 分钟重学；记忆牢固的词可能安排几十天后复习。
- 最长计划间隔为 **90 天**。不同评分触及上限时可能显示相同时间；到达上限不会自动停止复习。

### 取词与实际弹出时间

先处理当前词库中到期的复习词，再补新词。自动负荷平衡开启时，到期积压达到 40 个则每日新词配额减半，达到 80 个则暂停推新。

按钮显示的是计划间隔。冷却、暂停、当前词尚未处理或应用未运行，都可能使实际弹出晚于计划时间。设置中可以调整批次、冷却时间或选择连续模式。

进度预测根据剩余词量和每日新词配额估算新词完成日期，不表示届时已永久记住所有单词。

## 升级与数据

学习数据存储在 Electron 的用户数据目录，Windows 下通常为 `%APPDATA%\wordpop\`。建议通过设置页面定期导出备份，尤其在换机或重装系统前。

### 旧记忆记录的一次性更新

从旧版本升级后，首次启动自动更新到数据库 **schema v8**：

- 有连续 FSRS 评分日志的词，按当前反馈含义重新计算记忆状态，将旧 Hard 按回忆失败处理，并修复旧长期词跳过重学步骤的问题。
- 缺少连续日志的旧进度保留记忆估计，安排在 24 小时内重新评估；已经到期的词不会推迟。
- 保留词库、累计学习统计和原始评分日志；旧版已掌握且停止推送的词保持原状态。
- 更新前的进度存入数据库 `memory_initialization_archive` 表。更新在一个事务中完成，失败回滚，重启不会重复初始化。

### 备份与撤销

新备份保存 FSRS 状态及评分历史，也支持导入旧备份。撤销当前有效的评分会恢复原记忆状态和统计，并删除对应的本次评分日志。

## 技术架构与开发

应用使用 Electron 28、隔离的 preload API、原生 HTML／CSS／JavaScript 界面，以及 better-sqlite3 本地 SQLite 数据库。普通弹窗和专注模式共用 FSRS 计算与评分事务；独立胶囊只读取学习记录。

| 模块 | 职责 |
|---|---|
| `src/main/index.js` | 应用生命周期与模块组装 |
| `study-policy.js` / `study-scheduler.js` | 学习配额、取词、暂停、冷却与撤销 |
| `scheduler.js` / `scheduler-presenter.js` | 组装调度依赖，将学习事件交给窗口展示 |
| `focus-session.js` / `focus-window.js` | 专注学习业务与窗口生命周期 |
| `learning-repository.js` | 学习查询、统计、积压平摊及撤销数据访问 |
| `review-algorithm.js` / `review-progress.js` | FSRS 计算及评分、历史、统计的原子写入 |
| `db.js` / `fsrs-schema.js` / `memory-initialization.js` | 数据库、词库与旧记忆记录升级 |
| `ambient-words.js` / `ambient-pill-window.js` / `ambient-pill.js` | 胶囊候选词查询、窗口与轮播 |
| `popup-manager.js` / `config.js` / `backup.js` / `tray.js` | 卡片窗口、设置、备份与托盘 |
| `ipc-handlers.js` / `src/preload/preload.js` | 界面与主进程之间的隔离 API |
| `src/renderer/` | 卡片、专注、胶囊、设置与统计页面 |
| `src/data/` | 词库、词频及助记数据 |
| `test/` | 真实 SQLite、业务逻辑、Electron 窗口和更新检查回归 |

```bash
# 安装锁定依赖，并为 Electron 编译 SQLite 原生模块
npm ci

# 开发模式运行
npm run dev

# 运行测试，使用匹配原生模块的 Electron 运行时
npm test

# 在 Windows 上构建 x64 NSIS 安装包
npm run build -- --win --x64 --publish never
```

核心业务模块通过工厂函数注入数据库、时钟和计时器。测试覆盖真实 SQLite 事务、FSRS、调度和评分失败处理；界面测试运行实际 Electron 页面、preload 和 IPC，并使用临时数据目录隔离。

### 发布与保留规则

正式版代码在 **main**。推送正式版本标签（如 `v1.8.1`）会触发 [Windows 发布工作流](.github/workflows/windows-release.yml)：运行回归测试、构建安装包、验证包内功能，上传安装包和校验文件，再发布为正式 Latest Release。发布前应创建对应的 Release 草稿；也可通过工作流手动指定版本标签。

GitHub 按发布时间分别保留最近 **3 个正式版和 3 个测试版**。旧 Release 及附件自动清理，源码标签与分支保留。[清理工作流](.github/workflows/release-retention.yml) 在发布后执行，并提供每日巡检和手动入口。
